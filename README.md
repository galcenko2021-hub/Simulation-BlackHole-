# Simulation-BlackHole-
Симуляция чёрной дыры Шварцшильда в реальном времени: трассировка лучей на GPU, гравитационное линзирование, аккреционный диск с эффектом Доплера и красным смещением. Один файл на C++, OpenGL 3.3, без зависимостей.

# Black Hole — релятивистская симуляция чёрной дыры

Интерактивная 3D-симуляция чёрной дыры Шварцшильда. Каждый пиксель — луч света,
который видеокарта трассирует по точным геодезическим искривлённого пространства-времени.

## Что моделируется
- Гравитационное линзирование: тень, фотонное кольцо, вторичные изображения диска, кольцо Эйнштейна
- Аккреционный диск от ISCO (6M) с профилем температуры Новикова–Торна
- Цвет из спектра абсолютно чёрного тела (закон Планка + кривые CIE 1931)
- Релятивистский эффект Доплера, усиление яркости и гравитационное красное смещение
- Турбулентная структура диска с кеплеровским вращением
- Линзированное звёздное небо и Млечный Путь
- HDR, bloom, тональная компрессия ACES, сглаживание на паузе

## Сборка
Windows, видеокарта с OpenGL 3.3. Один файл, без сторонних библиотек.

- Visual Studio: консольный проект, конфигурация Release x64
- или из Developer Command Prompt: cl /O2 /EHsc blackhole.cpp

## Управление
| Действие | Клавиши |
|:--|:--|
| Вращение камеры | ЛКМ + мышь |
| Приближение | колесо / ПКМ + мышь |
| Пауза и сглаживание | Пробел |
| Доплер / красное смещение / линзирование / bloom | D / G / L / B |
| Температура диска | ↑ / ↓ |
| Скорость времени | ← / → |
| Скриншот | P |
